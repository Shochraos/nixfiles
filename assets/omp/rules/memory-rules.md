# Memory

Nothing is captured passively — automatic retention is off. A finding that is
not written down is lost.

- Any non-obvious fact established by doing the work goes to `retain`, or to
  `learn` when it is also a repeatable procedure, before yielding: a measured
  number, a disproven assumption, a footgun together with its symptom, a
  rejected design and the reason it was rejected.
- Write self-contained entries. A future session sees no transcript.
- Recall before proposing or executing anything architectural. Treat recall as
  necessary but not sufficient: retrieval is measurably lossy, so a clean
  recall is never evidence that no prior decision exists — check the project's
  own written record, the tree, and `git log` as well.

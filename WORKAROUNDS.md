# Workaround maintenance

Recheck these against the locked dependency sources when updating inputs. A clean evaluation does not prove that a native patch compiles or a hardware workaround is unnecessary. No upstream issue number is recorded where none has been verified.

| Location | Reason and verification | Removal condition |
| --- | --- | --- |
| `modules/base/nix.nix`, `assets/build-support/sphinx-hook.sh` | The pinned Sphinx hook loses builders in structured-attribute arrays. The local hook handles scalar, array and space-packed array forms. | The locked upstream hook handles all three forms and produces every declared documentation output without the overlay. |
| `modules/features/backup.nix`, `modules/graphical/sync.nix` | Their Sphinx pre-install hooks assume static files that newer Sphinx no longer provides. | The locked package hooks remove the static directory without relying on obsolete individual filenames. |
| `assets/patches/quickshell-hyprland-ipc-reconnect.patch` | Retry missing socket directories, failed status requests and event-socket disconnections for the current compositor signature. Build the patched package to verify compilation. A missing signature remains a launch-environment error; do not guess another compositor instance. | The locked Quickshell source provides equivalent startup and reconnect behavior. Test unavailable-at-start and disconnect/reconnect before dropping it. |
| `assets/patches/xdph-screencopy-buffer-reuse.patch` | Avoid buffer renegotiation from the screencopy callback. Retry at most ten times with backoff capped at one second; report exhaustion to PipeWire. | The locked portal avoids the callback-reentrancy bug and has a defined transient/permanent buffer-failure policy. Build the patched portal and test both paths. |
| `modules/graphical/plymouth.nix` Plymouth substitutions | Keep the configured spinner appearance through package rendering. | The selected upstream theme supports the same appearance without source substitutions. Compare the rendered theme before removal. |
| `modules/hosts/azazel/config.nix` NVMe APST override | Azazel retains `nvme_core.default_ps_max_latency_us=0` by explicit host policy; the affected device/firmware fault has not been established in this audit. Solas does not receive it. | The owner approves a controlled Azazel test demonstrating stable operation with normal APST across the relevant idle/resume workload. |
| `pkgs/rea/python.nix` | Optional Python backends need pwntools, pyelftools and unicorn rather than a bare interpreter. The package wrapper selects this environment. | The locked REA package supplies these backends itself, or the owner explicitly drops their support. Recheck the local version overrides when updating Python. |
| `pkgs/{rea,irony-mod-manager,mp3tag,bscpylgtv}` | These package recipes are maintained in this repository. REA also retains its Ghidra and Java runtime dependencies. | Equivalent maintained packages in the locked nixpkgs satisfy the runtime and integration requirements. Compare behavior before switching sources. |

SteamVR retains `cap_sys_nice=p`. The boot, path-triggered and one-minute fallback helper uses an open file descriptor, rejects symlinks and incorrect ownership, checks the current capability and verifies changes. This intentionally delegates that capability to the user's SteamVR launcher, not to arbitrary root-owned files. A SteamVR runtime test still requires the headset and the user's approval.
